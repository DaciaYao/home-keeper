# 家庭管家

厨房物品管理 + 衣橱穿搭助手。多家庭数据隔离、分类自定义、标签模糊搜索、拍照选图、加密备份导入、PWA 可安装到手机桌面。

## 一键部署

1. 把本目录所有文件上传到 GitHub 仓库
2. 在 [Netlify](https://app.netlify.com) 新建站点 → 关联仓库 → 部署
3. 访问分配的域名即可使用（需 HTTPS，PWA 必需）

## 首次使用

1. 首页输入「兔宝宝的家」→ 点「新建家庭」
2. 点「🍳 厨房」进入，添加食材（可填标签如"辛辣 麻"）
3. 同理使用「👔 衣橱」
4. 查找框输入关键词（如"辛辣"）→ 名称、分类、标签任一命中即显示

## 数据备份与恢复

### 手动加密备份（推荐，兼容所有云盘）
1. 点「🔒 加密备份」→ 设置密码 → 下载 `.enc.json` + `backup_meta.json`
2. 把两个文件一起上传到坚果云 / 百度网盘 / 夸克
3. 换设备时下载 `.enc.json` → 点「📥 导入数据」→ 输密码恢复
4. 点「🔄 检查更新」→ 选取网盘里的 meta 文件 → 比对版本

### 坚果云一键同步
1. 点「☁️ 云盘同步」→ 选「坚果云 (WebDAV)」
2. 填服务器地址 `https://dav.jianguoyun.com/`、邮箱、**应用专用密码**
3. 需先在坚果云设置里开启 WebDAV（设置 → 第三方应用管理）
4. 点「测试连接」→「⬆️ 上传全部」/「⬇️ 下载全部」

### 百度网盘
百度 OAuth 换 Token 必须走后端。未部署后端时，请使用「加密备份」手动上传。

## 安装到手机（PWA）

首次打开网站会自动弹出「添加到主屏幕」横幅；也可手动：
- Android Chrome：菜单 ⋮ → 添加到主屏幕
- iPhone Safari：分享按钮 → 添加到主屏幕
- 电脑 Chrome/Edge：地址栏安装图标
